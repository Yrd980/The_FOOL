# V0.2 Foundation Slice Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a safe V0.2 foundation slice by adding replay schema versioning, introducing engine and LLM seams, and tightening CLI/mock-agent behavior with regression tests.

**Architecture:** Start by adding a test safety net around pure engine behavior and the new replay contract. Then refactor engine orchestration to depend on `EngineContext` and an `LLMProvider` interface instead of repeated callback bundles and a hard-coded DeepSeek client. Finish with CLI and mock-agent behavior fixes that stay independent from the larger Viewer split.

**Tech Stack:** TypeScript, Bun, React/Vite viewer build, AJV 2020

**Spec:** `docs/superpowers/specs/2026-03-12-v0.2-architecture-design.md`, `docs/superpowers/specs/2026-03-12-v0.2-feature-backlog-design.md`

const BETRAY_THRESHOLD = 0.2;
