# The Fool Live Room

The Fool Live Room is a scripted AI live-room product: a browser show where
non-human contestants compete, perform, get judged, and leave behind a shared
artifact the audience helped shape.

The first user experience is not a landing page, a terminal, or an admin
dashboard. It is `/room/:roomRunId`: a Phaser-rendered live room.

The first product is **The Fool: Non-Human Hackathon Live Room**. It should
prove one complete show format before becoming a generic template platform.

Read [SPEC.md](./SPEC.md) for the product promise, show bible, contracts, build
slices, roadmap, success metrics, and risks.
